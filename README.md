# A Jazz Lover's Guide to Chicago

An interactive e-learning course built as a proof of concept demonstrating that a fully functional Articulate Storyline-style module can be built in pure HTML/CSS/JS — no Storyline required.

## Overview

This course is designed for jazz appreciators (newcomer to deep fan) visiting or new to Chicago. It covers Chicago's jazz history, key artists, where to hear live jazz, an interactive quiz, and a personal event planner.

## Tech Stack

- Pure HTML/CSS/JS — no frameworks, no build tools
- Google Fonts (Bebas Neue + Inter)
- Single file: `index.html`
- Deploy anywhere that serves static files

## Deploy to Vercel

1. Connect this repo to Vercel
2. No configuration needed — Vercel detects static HTML automatically
3. Deploy
